# Разработка

- `bot.py` обрабатывает сценарии, `db.py` хранит пользователей и заявки, `payment.py` обращается к ЮMoney.
- Настройки читаются только из окружения через `config.py`. Не добавлять реальные токены, кошельки, адреса сервиса и данные клиентов.
- Платёж проверяется по владельцу, метке, входящему направлению, сумме и статусу. Переход из `pending` выполняется атомарно в PostgreSQL.
- Админские действия требуют серверной проверки роли. Денежные расчёты выполняются через `Decimal`.
- Изменения схемы существующей базы требуют миграций, сохранения данных и проверки на изолированном PostgreSQL.
- Команда проверки: `uv run --frozen python check.py`. Тесты не обращаются к Telegram, ЮMoney и рабочей базе.
- Не публиковать `.env`, дампы и логи. Перед push проверить дерево Git через `gitleaks git --redact`.
